# Simulacao_Financeira

Este repositório contém uma simulação de financiamento imobiliário com suporte a FGTS, entradas parceladas pela construtora, balões pontuais, despesas fixas e pontuais por data, renda extra isenta, cálculo de juros e amortização, consolidação por mês/ano, export CSV e coluna de saldo acumulado. O objetivo é oferecer uma ferramenta interativa em HTML/JS que permita analisar fluxo de caixa mensal e impactos de diferentes estratégias de entrada e uso de FGTS.
